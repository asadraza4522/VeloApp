# Velo Vector Brand Assets

Primary visual direction:
- Dark navy foundation
- Cyan/blue/purple gradient V/play mark
- Teal download arrow
- Clean geometric/ribbon construction
- Poppins/Inter-style wordmark treatment
- Tagline: “Save. Convert. Organize.”

Core colors:
- Dark Navy: #081A3D
- Deep Navy: #071442
- Primary Blue: #168AF4
- Cyan: #39DDF5
- Purple: #6A32FF
- Violet: #C04DFF
- Teal: #18D5C5
- Download Green: #42E9B4
- White: #FFFFFF
- Ink: #0A1020

Files:
icons/    Icon-only vector masters
logos/    Wordmark and tagline vector masters
android/  Android adaptive icon vector XML
ios/      iOS implementation notes
brand/    This documentation

Important production note:
The icon geometry is vector and scalable. The wordmark uses SVG text with
Poppins/Inter/Arial fallback rather than embedded font outlines. Before final
commercial release, convert the chosen wordmark text to outlines in Figma,
Illustrator, or Inkscape to eliminate font dependency.
